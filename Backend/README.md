# E-learning Backend

## Hugging Face Deployment
This space runs the backend for the E-learning Management System using Docker.

### Local Development
1. `npm install`
2. `npm start`

### Configuration
Ensure you set the `MONGODB_URI` secret in the Space settings for database connectivity.
